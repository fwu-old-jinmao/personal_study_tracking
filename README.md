# Personal Learning Tracker

个人学习项目追踪系统 — 用于记录和管理读书、在线课程、音频课程等学习项目的进度、状态与完成情况。

## 项目状态

🚧 **开发中** — M1 项目管理 + M2 Kanban 看板 + M3 每日进度录入已完成，后续模块逐步上线

## 已实现功能

### M1 - 项目管理
- **创建项目**：支持书籍、课程、其他三种类型
- **编辑项目**：修改项目信息、调整进度配置、设置起始/预期完成日期
- **删除项目**：含确认对话框，删除后级联清除关联数据
- **项目列表**：支持按名称搜索、按类型/状态筛选
- **进度类型支持**：
  - **线性型**（书籍页数 / 视频集数）
  - **层级型**（Module / Part 结构，Module 名称自动递增）
  - **百分比型**（手动输入百分比）

### M2 - Kanban 看板
- **四列状态管理**：规划中 → 进行中 → 暂缓 → 已完成
- **状态流转**：通过按钮操作切换项目状态
- **类型筛选**：按书籍/课程/其他过滤看板内容
- **进度显示**：根据进度类型智能显示（书籍：`342/1078页`，课程：`15/40Part`，其他：百分比）
- **已归档区**：独立展示已归档项目

### M3 - 每日进度录入
- **日期切换**：支持今天/昨天/前天快捷切换，可手动选择日期补录
- **项目快速选择**：下拉搜索 + 最近活跃项目快捷按钮
- **动态表单**：根据项目进度类型自动切换录入界面
  - **线性型**：自动填充上次截止位置，输入本次截止页/集
  - **层级型**：选择 Module → 输入 Part 范围，Module 完成后自动跳转下一个
  - **百分比型**：滑块拖动输入进度
- **实时预览**：录入时显示本次推进量和累计进度百分比
- **今日录入列表**：右侧展示当天所有记录，支持删除
- **连续录入**：保存后自动重置表单，可继续录入同一项目

### M4 - 完成项目展示
- **日视图**：查看/修改某天的完成项目明细，支持修改完成日期和撤销完成
- **周视图**：本周完成项目列表，可前后翻周
- **月视图**：月度统计卡片 + 按周分组展示，可前后翻月
- **年视图**：年度统计卡片 + 按月时间轴展示，可前后翻年

### M5 - 可视化统计
- **汇总卡片**：进行中/暂缓/规划中/本周完成/本月完成/连续活跃天数
- **推进量趋势图**：近30天柱状图 + 折线图，展示每日推进量和项目数
- **类别分布饼图**：已完成项目的书籍/课程/其他占比
- **年度活跃热力图**：日历热力图，颜色深浅表示当天学习量

## 技术栈

| 层面 | 技术 |
|------|------|
| 后端 | Python 3.10+ |
| 前端框架 | NiceGUI 3.x（底层 Vue 3 + Quasar） |
| 数据库 | SQLite |
| 可视化 | ECharts（通过 NiceGUI 集成） |

## 快速开始

### 环境要求

- Python 3.10+
- pip

### 安装与运行

```bash
# 1. 克隆仓库
git clone https://github.com/your-username/personal-learning-tracker.git
cd personal-learning-tracker

# 2. 安装依赖
pip install nicegui

# 3. 启动应用
python app.py
浏览器自动打开 http://localhost:8080
```

## 项目结构
```text
personal-learning-tracker/
├── app.py                    # 应用入口，页面路由
├── config.py                 # 配置文件（状态、类型、标签定义）
├── models.py                 # 数据模型（dataclass）
├── database.py               # 数据库初始化与操作
├── services/                 # 业务逻辑层（与UI框架解耦）
│   ├── project_service.py    # 项目 CRUD
│   ├── progress_service.py   # 进度记录
│   └── stats_service.py      # 统计分析
├── ui/                       # UI 层
│   ├── components/           # 可复用组件
│   │   └── project_card.py   # 看板卡片
│   └── pages/                # 页面
│       ├── projects.py       # 项目管理页面
│       ├── kanban.py         # Kanban 看板页面
│       ├── log.py            # 每日进度录入页面
│       ├── history.py        # 完成记录页面
│       └── stats.py          # 统计分析页面
└── data/                     # SQLite 数据库文件存放
    └── tracker.db            # 运行后自动生成
```

## 设计原则
- 业务与UI分离：services/ 层纯 Python 逻辑，不依赖任何 UI 框架，为未来迁移到 Vue/React 前端预留空间

- 本地优先：SQLite 本地存储，无需网络，数据安全可控

- 渐进开发：按模块逐步上线，每个模块独立可用
